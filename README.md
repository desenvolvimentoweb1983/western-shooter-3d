# Western Shooter 3D

Jogo de tiro 3D em JavaScript + Three.js + Vite.

## Requisitos
- Node.js 20 ou superior
- npm

## Instalação
```bash
npm install
npm run dev
```

Abra o endereço local mostrado pelo Vite.

## Controles
- W A S D: mover
- Shift: correr
- Mouse: mirar
- Clique esquerdo: atirar
- R: recarregar
- ESC: pausar/continuar

## Gerar versão de produção
```bash
npm run build
npm run preview
```

A pasta `dist/` será criada pelo Vite.
